# Prerequisites

之前学到的 [AVL Tree](/data-structures-algorithms/ads/avl-tree/) 和[红黑树](/data-structures-algorithms/ads/red-black-tree/)（包括其上位概念二叉搜索树），都是把数据全部加载到内存中，然后在内存中进行处理的，通常不会有太大的数据量。
如果数据规模太大，就无法把大规模数据一次性读到内存当中，此时只能分批次地把需要处理的数据从硬盘调到内存中。 我们把该过程称为一次~={cyan}硬盘访问=~或一次~={cyan}硬盘 IO=~。

> 处理数据的操作由 ==CPU== 执行，而 CPU 无法直接和硬盘交互，硬盘中的数据必须调到内存中才可以和 CPU 交互。

然而，这种访问是非常缓慢的。内存的单次访问是 ns 级，而硬盘的则是 ms 级。一次硬盘访问的成本相对而言是很高的。对于二叉搜索树而言，每往下找一层就需要一次访问——硬盘访问次数和树~={orange}高=~正相关。在这种情况下，使用 AVL 树和红黑树是很低效的。为了在数据量不变的情况下降低树高，B 树应运而生。

# 定义

- ~={pink}**多叉平衡搜索树**=~
- 每个结点不止一个数据，这样树高随之被压缩，访问次数减少

> 硬盘特性：读取物理地址连续的多个字节和读取单个字节的耗时几乎没有区别。如读取 1B 需要 8ms 用于寻道 + 旋转，0.01ms 用于数据传输；读取连续的 4KB 则需要 8ms 用于寻道 + 旋转，0.02ms 用于数据传输。这使得即使每个结点中多了几个元素，硬盘对此也无所谓。

- 包含数据的结点称为~={yellow}**内部结点**=~
- 不包含数据的空结点称为~={yellow}**外部结点**=~（或~={yellow}**失败结点**=~）
- 一般认为叶结点指内部结点的最后一层，也有教材认为指外部结点

# 特性

## 1. 平衡

- 所有的叶结点都在同一层

## 2. 有序

- 结点内有序：
	- 任一元素的左子树都小于它，右子树都大于它

## 3. 多路

阶数是事先规定的。
对于 m 阶 B 树的结点：

- 分支树 = 结点数 + 1
- 最多：m 个分支，m - 1 个元素
- 最少：
	- 根结点：2 个分支，1 个元素
	- 其他结点：$\left\lceil \frac{m}{2} \right\rceil$ 个分支，$\left\lceil \frac{m}{2} \right\rceil -1$ 个元素
	- 失败结点并不被包括在内

# 操作

## 查找

B 树的查找和二叉搜索树的查找非常类似。
如果遇到有多个元素的结点，可以把要找的数据依次和每个元素进行比较，直到找到第一个比要找的数据大的元素，此时就走该元素的~={cyan}左子树=~；如果一直比完了最后一个元素都没有找到，就走~={orange}最右边的子树=~。
如果走到了失败结点，即意味着~={red}查找失败=~。

> 访问结点在~={pink}硬盘=~上进行；结点内查找在~={pink}内存=~中进行。

## 插入

- 插入一定会落在~={green}叶子结点=~上
- 插入之后，要检查该结点的元素数量是否超出上限（~={cyan}**上溢出**=~），如果超出（破坏了 B 树的性质），需要进行调整：
	- 找到中间元素（第 $\left\lceil \frac{m}{2} \right\rceil$ 个），将其上移到父结点中合适的位置
		- 如果该步骤导致父结点上溢出，则继续处理父结点，直到没有上溢出为止
		- 如果根结点发生上溢出，会创建新的根结点
	- 中间元素两边的元素分裂成两个结点
		- 如果不是叶子结点，要连带着其子树一起分裂

## 构建

尝试模拟 B 树的构建过程可知，它更像是一棵向上生长的树，而非通常的向下。

## 删除

- 删除操作和插入相反，可能会导致~={cyan}**下溢出**=~，即结点元素数量低于最低要求
- 删除的第一步操作和二叉搜索树相同：用直接前驱或直接后继替换该元素，然后删除掉原来位置上的元素
	- 也就是说，~={yellow}**删除任何位置的元素最后都会转化为删除叶子结点上的元素**=~
- 如果删除后出现下溢出：
	- 找左或右兄弟借，如果都够借就随便找一个借
		- 借法：把共同的父元素下移到下溢出的结点中，并把兄弟结点中最接近父元素的元素挪上去
	- 如果左右兄弟都不够借，就随便找一个兄弟合并
		- 合并法：以和左兄弟合并为例，先让父元素下移到左兄弟，再把下溢出结点并过来，最后移除空的父元素和子树；和右兄弟则相反
		- 合并操作可能让父结点也出现下溢出，此时处理方式同理，注意移动元素时要捎带上可能存在的子树！
