---
title: "AVL Tree"
---

- 全称为 **Adelson-Velsky and Landis Tree**
- 中文通常称为~={green}**平衡二叉树**=~/~={cyan}**平衡二叉搜索树**=~
- 它是一种高度平衡的二叉搜索树

# 来由

在二叉搜索树的构建过程中，数据插入顺序不同会影响树的形状，进而影响各种操作的时间复杂度。例如，单调地插入一组数据会使普通二叉搜索树退化为链表，使查找、插入和删除从平均或理想情况下的 $O(\log n)$ 退化到最坏 $O(n)$。AVL 树通过维护高度平衡来避免这种退化。

相对于一般的二叉搜索树，AVL 树引入了平衡因子和旋转两个概念。

# 平衡因子

- 令 $h_L$ 为某个结点左子树的高度，$h_R$ 为其右子树的高度，则该结点的平衡因子为 $BF=h_L-h_R$。
- 若 $|BF|\le 1$，则称该结点是平衡的。
- 空二叉树是平衡的。空树高度取 $0$ 或 $-1$ 均可，但整棵树必须使用同一种约定。

# 旋转操作

当一次插入或删除使结点失衡时，需要对以该结点为根的子树进行旋转。

| 失衡结点 $z$ 的 BF | 较高一侧子结点的 BF | 类型 | 操作 |
|---:|---:|---|---|
| $2$ | $\ge 0$ | LL | 对 $z$ 右旋 |
| $2$ | $<0$ | LR | 先对左子树左旋，再对 $z$ 右旋 |
| $-2$ | $\le 0$ | RR | 对 $z$ 左旋 |
| $-2$ | $>0$ | RL | 先对右子树右旋，再对 $z$ 左旋 |

> 插入导致的第一个失衡结点，其较高子结点的 BF 通常为 $\pm1$；删除时可能出现 BF 为 $0$ 的情况，此时仍采用单旋。

## 图示

### 右旋

```
        z                   y
       / \                 / \
      y   T3      →       T1  z
     / \                     / \
    T1 T2                   T2 T3
```

### 左旋

```
        z                     y
       / \                   / \
      T1  y       →         z  T3
         / \               / \
        T2 T3             T1 T2
```

# 注意

- 插入时只需旋转从插入结点向上遇到的~={red}第一个失衡祖先=~；旋转后该子树的高度恢复，因此更高祖先不再需要旋转。
- 删除可能使子树高度继续降低，因此需要~={red}依次检查并调整所有祖先=~，最坏可能进行 $O(\log n)$ 次再平衡。
- 每次旋转后都要按从下到上的顺序更新相关结点的高度。

# 时间复杂度

AVL 树始终保持高度为 $O(\log n)$，因此主要操作的最坏时间复杂度为：

| 操作 | 最坏时间复杂度 |
|---|---|
| 查找 | $O(\log n)$ |
| 插入 | $O(\log n)$ |
| 删除 | $O(\log n)$ |
