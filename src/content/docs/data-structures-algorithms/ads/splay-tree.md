---
title: "Splay Tree"
---

- Splay Tree（伸展树）是一种~={cyan}自调整二叉搜索树=~
- 它不保存高度或颜色，也不保证树在任意时刻严格平衡
- 它使用与 [AVL Tree](/data-structures-algorithms/ads/avl-tree/) 相同的左旋、右旋基本操作
- 核心特点：每次访问后都执行 Splay，将目标结点旋转到~={cyan}根结点=~

## 不同操作中的目标结点

- 成功查找：把找到的结点旋转到根。
- 查找失败：通常把最后访问的结点旋转到根。
- 插入：把新插入的结点旋转到根。
- 删除：先把待删除结点旋转到根，再删除并合并左右子树；被删除结点不会留在树中。

# Splay 操作

- 用到目标结点 $x$、其父结点 $p$ 和祖父结点 $g$。
- 分为三大类：Zig、Zig-Zig、Zig-Zag。
- 重复执行相应操作，直到 $x$ 成为根结点。

| 情况 | 结构 | 操作 |
|---|---|---|
| Zig（左） | $p$ 是根，$x$ 是 $p$ 的左儿子 | 对 $p$ 右旋 |
| Zig（右） | $p$ 是根，$x$ 是 $p$ 的右儿子 | 对 $p$ 左旋 |
| Zig-Zig（左左） | $x$ 是 $p$ 的左儿子，$p$ 是 $g$ 的左儿子 | 先对 $g$ 右旋，再对 $p$ 右旋 |
| Zig-Zig（右右） | $x$ 是 $p$ 的右儿子，$p$ 是 $g$ 的右儿子 | 先对 $g$ 左旋，再对 $p$ 左旋 |
| Zig-Zag（左右） | $x$ 是 $p$ 的右儿子，$p$ 是 $g$ 的左儿子 | 先对 $p$ 左旋，再对 $g$ 右旋 |
| Zig-Zag（右左） | $x$ 是 $p$ 的左儿子，$p$ 是 $g$ 的右儿子 | 先对 $p$ 右旋，再对 $g$ 左旋 |

# 删除与合并

删除结点 $x$ 的一种标准做法：

1. 查找 $x$ 并将其 Splay 到根。
2. 删除根，得到左子树 $L$ 和右子树 $R$。
3. 若 $L$ 为空，直接令根为 $R$。
4. 否则把 $L$ 中的最大结点 Splay 到 $L$ 的根。此时该根没有右儿子，再把 $R$ 接到它的右侧。

# 层数与旋转次数

若根是第 $1$ 层，目标结点在操作前位于第 $L$ 层，则：

$$
\text{双旋步骤数}=\left\lfloor\frac{L-1}{2}\right\rfloor
$$

- 当 $L$ 为偶数时，最后还需要一次 Zig。
- 若把一次 Zig-Zig 或 Zig-Zag 计作两次基本旋转，则基本旋转总数为 $L-1$。

# 时间复杂度

- 单次操作的最坏时间复杂度可能为 $O(n)$。
- 任意操作序列上的~={cyan}摊还时间复杂度=~为 $O(\log n)$。
- 因此查找、插入和删除的摊还时间复杂度均为 $O(\log n)$。
- Splay Tree 不保证高度始终为 $O(\log n)$；它的性能保证来自摊还分析，而不是每一步都保持平衡。
