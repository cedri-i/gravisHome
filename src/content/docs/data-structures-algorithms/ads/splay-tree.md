---
title: "Splay Tree"
---

- 和 AVL Tree 一样，它也是二叉搜索树的子集
- 它不维持平衡，但和 AVL Tree 使用同一套左旋、右旋规则
	- 具体方式参考 [AVL Tree](/data-structures-algorithms/ads/avl-tree/) 一篇
- 核心特点：
	- 成功查找或插入的目标结点会被旋转到根结点
	- 查找失败时，通常把最后访问的结点旋转到根结点
	- 删除时，先把目标结点旋转到根结点再删除
# Splay 操作
- 用到：该节点 $x$、该节点的父节点 $p$、该节点的祖父节点 $g$
- 分为三大类：Zig、Zig-Zig、Zig-Zag

| 情况 | 结构 | 操作 |
|---|---|---|
| Zig（左） | $x$ 是根节点 $p$ 的左儿子 | 对 $p$ 右旋 |
| Zig（右） | $x$ 是根节点 $p$ 的右儿子 | 对 $p$ 左旋 |
| Zig-Zig（左左） | $x$ 是 $p$ 的左儿子，$p$ 是 $g$ 的左儿子 | 先对 $g$ 右旋，再对 $p$ 右旋 |
| Zig-Zig（右右） | $x$ 是 $p$ 的右儿子，$p$ 是 $g$ 的右儿子 | 先对 $g$ 左旋，再对 $p$ 左旋 |
| Zig-Zag（左右） | $x$ 是 $p$ 的右儿子，$p$ 是 $g$ 的左儿子 | 先对 $p$ 左旋，再对 $g$ 右旋 |
| Zig-Zag（右左） | $x$ 是 $p$ 的左儿子，$p$ 是 $g$ 的右儿子 | 先对 $p$ 右旋，再对 $g$ 左旋 |
# 经验公式
- 一般地，若根是第 1 层、访问节点位于第 $L$ 层：
$$双旋次数=⌊\frac{L-1}{2}⌋$$
- 该式统计的是双旋步骤；若 $L$ 为偶数，最后还会有一次 Zig。
# 时间复杂度
- 单次操作最坏为 $O(n)$，摊还时间复杂度为 $O(\log n)$。
